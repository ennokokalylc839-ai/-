# 微信戒色小程序

这是一个帮助用户记录戒色进度、培养良好习惯并收集支持资源的微信小程序项目。小程序完全基于本地存储，适合作为个人自律工具使用。

## 主要功能

- **首页概览**：展示连续坚持天数、最新记录、今日任务完成情况与每日励志语。
- **进度记录**：记录每日坚持或破戒情况，支持备注触发诱因，自动统计连续坚持天数与距离上次破戒的时间。
- **习惯任务**：提供默认习惯清单，可标记每日完成情况并新增自定义任务，支持一键重置当日任务状态。
- **资源工具**：汇总应急自救步骤、专注技巧与学习资源，支持复制外部链接或直接拨打求助电话。

## 目录结构

```
project.config.json   # 微信开发者工具项目配置
miniprogram/
├── app.js            # 全局数据（默认习惯、资源等）
├── app.json          # 全局页面配置
├── app.wxss          # 全局样式
├── sitemap.json      # 小程序索引配置
├── utils/
│   └── quotes.js     # 励志语句工具
└── pages/
    ├── home/         # 首页概览
    ├── progress/     # 进度记录
    ├── tasks/        # 习惯任务
    └── resources/    # 资源工具
```

## 使用方式

1. 将项目导入微信开发者工具，`miniprogram` 目录为小程序代码根目录。
2. 在真机或模拟器中体验，所有数据均存储在本地 Storage，无需搭建后端。
3. 如需扩展功能，可在 `app.js` 中调整默认任务与资源列表，或在各页面逻辑中接入云开发能力。

欢迎根据自身需求进行二次开发，祝你坚持自律，保持专注！
